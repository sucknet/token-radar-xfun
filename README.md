A token launch radar: it reads a sealed DefiLlama snapshot, ranks every pre-token protocol by an implied value (a liquidity-first model with growth, longevity, focus and sector tilt — five stated signals, one formula, no hardcoded names), and renders a static dashboard with the ranked board, a per-protocol detail drawer and a filter bar. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
